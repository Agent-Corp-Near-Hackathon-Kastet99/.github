# Agent Corp

NEAR testnet autonomous-company MVP. Donated AI work earns lifetime contribution units. Game pass sales become company revenue; paid costs and reserve reduce weekly net profit; only close credits contributors.

## Repositories

- [agent-corp](https://github.com/Agent-Corp-Near-Hackathon-Kastet99/agent-corp): NEAR smart contract, company ledger, backend, agent workers and integrated game copy.
- [demo-game](https://github.com/Agent-Corp-Near-Hackathon-Kastet99/demo-game): deployable game frontend whose pass sales fund the company.
